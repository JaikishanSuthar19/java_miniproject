Problem Definition

Problem Statement & Motivation

Addressing academic enrollment friction, seat contention, and institutional governance.
The Core Problem
Challenges with Manual / Traditional Systems
  • Course Over-Enrollment: Lack of real-time seat locks leads to classrooms exceeding maximum physical capacity.
  • Duplicate Registrations: Students inadvertently registering for duplicate sections, consuming limited seats.
  • Disconnected Faculty Administration: Faculty allocations maintained separately from live student course catalogs.
  • Schedule Uncertainty: Absence of instant feedback regarding credit caps and registration status.
The Solution
Our Digital Approach
  • Dual-Role Portals: Distinct tailored environments for Students and Administrators.
  • Real-Time Capacity Guards: Instant vacancy recalculation on enrollment and seat restoration upon cancellation.
  • Enterprise Validation Rules: Strict prevention of duplicates, full courses, and exceeding the 18-credit semester limit.
  • Synchronized State Architecture: Cross-panel auto-refresh ensuring consistent data views across all tabs.

Computer Science Foundations

Java Collections Framework Deep Dive

Algorithmic complexity comparison and design rationale for each collection type.
Fixed Memory
Course[] (Array)
Time Complexity: O(1) Index Access

Fulfills Objective 4. Used in DataStore for predefined initial courses. Resized dynamically using System.arraycopy when capacity expands.

Audit Trail
LinkedList<Reg>
Time Complexity: O(1) Appends

Fulfills Objective 5. Maintains sequential transaction records. Appends registrations in constant time without requiring contiguous memory reallocations.

Fast Search
HashMap<ID, T>
Time Complexity: O(1) Average

Fulfills Objective 6. Stores Students, Courses, and Faculty indexed by unique ID strings. Powers immediate authentication and instant detail fetching.

Self-Sorting
TreeMap<ID, Course>
Time Complexity: O(log N)

Fulfills Objective 7. Backed by a Red-Black Tree. Guarantees courses are always presented in alphabetical order across tables and dropdowns without manual sorting.
